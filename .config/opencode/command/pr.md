Prepare an submit a pull request to the current repository to propose the changes you've made in this session.

- make sure you're on a clean branch, freshly rebased against `main`, and whose name follows the pattern !`whoami`/3-words-description
- use conventional commit standards for the PR title. If in a monorepository, use `project` as the scope, eventually `project/feature`.
- if there is a PR template in the `.github` folder of the repo, try to respect it.
